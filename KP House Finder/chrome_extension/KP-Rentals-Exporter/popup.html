Facebook group
How to use
  1. Open the group feed and scroll to the top.
  2. Set a post limit and/or a stop date (optional).
  3. Hit Grab posts — it scrolls and collects on its own.
  4. Progress saves continuously — syncs to Supabase or download JSON when done.
posts
How these work
Grabs from today backward to the stop date.
  • Blank post count = no limit.
  • Both blank = the whole feed.
  • Recent and undated posts are always kept.
  • You can also press Stop on the page panel at any time.

WhatsApp Web
How to use
  1. Open the group chat.
  2. Set a message target and/or a stop date (optional).
  3. Hit Start grabbing, then scroll up by hand.
  4. Progress saves continuously — syncs to Supabase or download JSON when done.
messages
How these work
You scroll up by hand; these act as targets.
  • Blank message count = no limit.
  • Both blank = everything you scroll past.
  • Recent and undated messages are always kept.
  • The panel shows when a target is reached, so you know when to stop scrolling.
